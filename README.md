# Blantyre District Markets – Dijkstra & MST
22 markets in Blantyre District, 46 road links (distances in metres). C++ implementation + interactive web demo.
- Live demo: https://lusekelo-1051.github.io/blantyre-markets/
- Build: g++ -std=c++17 -O2 dijkstra.cpp -o dijkstra
- Shortest path: dijkstra graph.txt shortest Chileka_Market Machinjiri_Market --trace
- MST (Kruskal): dijkstra graph.txt mst
- Full test log: docs/test_log.txt   Report: docs/DSA_Assignment_Report.pdf
